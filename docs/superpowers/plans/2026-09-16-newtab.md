# NewTab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Firefox new-tab extension with command palette, clock, two shortcut groups, Pomodoro, study heatmap and word of the day.

**Architecture:** Preact UI in `newtab.html`, background event script for the Pomodoro timer. Pure logic lives in framework-free modules (`*/logic.ts`) with Vitest tests; components only render and dispatch. All persistence goes through `src/storage`, which wraps `browser.storage.local` behind a small `StorageArea` interface so tests use an in-memory fake.

**Tech Stack:** Preact 10, TypeScript 5, Vite 6, Vitest 3 (jsdom), @fontsource-variable fonts, web-ext.

**Spec:** `docs/superpowers/specs/2026-09-16-newtab-design.md`

## Global Constraints

- Firefox only, Manifest V3, `browser_specific_settings.gecko.id = "newtab@ldleader"`, `strict_min_version = "128.0"`.
- Permissions: `storage`, `alarms`, `notifications`, `unlimitedStorage`. Host permissions: `https://icons.duckduckgo.com/*`, `https://www.google.com/*`, `https://api.dictionaryapi.dev/*`.
  - **Deviation from spec §10:** favicon services answer 404 *with a placeholder image*, so `<img onerror>` cannot detect a missing icon. Icons are fetched, `response.ok` is checked, and the result is cached as a data URL. That needs host permissions.
- UI strings in Turkish via `t(key)`; `_locales/tr` and `_locales/en` both exist.
- Max 10 shortcuts per group, 5 rows per column.
- Default font JetBrains Mono, bundled; no network font requests.
- Link-icon tile style taken from Bonjourr "inline" layout: `--link-padding: 0.3em`, `--link-outer-radius: 0.6em`, inline factor 0.43, icon 2em, title max-width 8.4em. Bonjourr is GPL-3.0; project license is GPL-3.0 because Bonjourr SVG icons are reused.
- Every commit ends with the session attribution trailer.

### Task 2: Shared types, defaults, time helpers

**Produces:**
- `types.ts`: `Settings`, `Shortcut`, `Groups`, `Command`, `ActionId`, `TimerState`, `Session`, `WordState`, `Word`, `DictionaryData`, `WidgetId` exactly as spec §5.
- `defaults.ts`: `DEFAULT_SETTINGS`, `DEFAULT_GROUPS` (empty), `DEFAULT_COMMANDS` (spec §6 table), `DEFAULT_TIMER`, `DEFAULT_WORD_STATE`, `SCHEMA_VERSION = 1`.
- `time.ts`: `formatClock(date, {h24, seconds}) → string`, `formatDate(date, locale) → string` (`16 Eylül Çarşamba`), `dayKey(date|ms) → 'YYYY-MM-DD'` (local), `formatDuration(min) → '1 sa 25 dk'`, `formatCountdown(ms) → 'MM:SS'`.
- `id.ts`: `newId() → string`.

**Tests:** formatClock 24h/12h/seconds; formatDate TR; dayKey near midnight uses local time; formatDuration 0/45/60/85; formatCountdown rounds up (59_001 ms → `01:00`), never negative.

### Task 3: Storage layer

**Produces:**
- `area.ts`: `interface StorageArea { get(key): Promise<unknown>; set(items): Promise<void>; remove(key): Promise<void>; onChanged(cb: (changes: Record<string, unknown>) => void): () => void }`, `browserArea`.
- `store.ts`: typed keys `settings | groups | commands | timer | sessions | word | favicons`; `load<K>(area, key)`, `save<K>(area, key, value)`, merging stored partial with defaults.
- `migrate.ts`: `migrate(raw: unknown) → { settings, … }` by `schemaVersion`; unknown/corrupt → defaults.
- `backup.ts`: `exportData(area) → string`, `importData(area, json) → { ok: true } | { ok: false, error }` with shape validation; on failure nothing is written.
- `images.ts`: IndexedDB `putBackground(blob)`, `getBackground() → Blob|null`, `clearBackground()`.
- `useStored(key)` hook: `[value, setValue]`, updates on `onChanged`.

**Tests (memory area fake):** load returns defaults when empty; partial settings merged deep with defaults; save then load round-trip; onChanged fires; migrate corrupt → defaults; import rejects invalid JSON, wrong shape, >10 shortcuts in a group, and leaves data untouched; export→import round-trip.

- **Test:** `applyTheme` sets vars; Clock renders formatted time with fake timers.

### Task 5: Shortcut logic

**Produces (`shortcuts/logic.ts`):**
- `MAX_PER_GROUP = 10`, `ROWS = 5`
- `normalizeUrl(input) → string | null` (adds `https://`, rejects invalid / no dot unless `localhost`)
- `titleFromUrl(url) → string` (`www.github.com` → `Github`, `localhost:3000` → `localhost:3000`)
- `addShortcut(groups, side, shortcut) → Groups` (throws `GroupFullError` when 10)
- `updateShortcut`, `removeShortcut(groups, id)`
- `gridCells(list) → Array<{ kind: 'site', shortcut } | { kind: 'add' }>` with add cell only when `< 10`; `cellPosition(index) → { col: 1|2, row: 1..5 }` (column-first fill).
- `letterFor(title)`, `colorFor(domain) → hsl string` (stable hash).

**Produces (`shortcuts/favicon.ts`):** `faviconSources(domain) → string[]` (DDG then Google), `resolveFavicon(domain, fetchFn, cache) → dataUrl | null` — first `ok` image response wins, result (including null) cached per domain for 7 days.

**Tests:** all above, including 6th item goes to col 2 row 1, add cell at index 10 absent, favicon falls through 404 → 200 and caches.

### Task 7: Palette logic

**Produces (`palette/logic.ts`):**
- `parseInput(text) → { trigger, query }` (first whitespace split, trimmed)
- `rankCommands(commands, text) → Command[]` — exact > prefix > includes on trigger (case-insensitive), ties by `uses` desc then trigger asc; empty text → `[]` (grouped view handled separately)
- `groupCommands(commands) → { action, link, search }` each alphabetical
- `resolveCommand(cmd, query) → { type: 'url', url } | { type: 'action', actionId, arg }` — search with empty query opens template origin; query `encodeURIComponent`
- `validateTrigger(commands, trigger, selfId?) → 'ok' | 'empty' | 'spaces' | 'duplicate'`

**Tests:** each rule incl. `yt lofi beats` → `lofi%20beats`, `tag Matematik` → action arg, ties, duplicate trigger.

### Task 8: Palette UI + actions

Palette.tsx (compact → expanded on hover/focus, backdrop dim, list, ↑↓ Enter Ctrl+Enter Esc, shake on no match), global keydown `Ctrl+K` and `/` (ignored when typing in inputs). `actions.ts`: `runAction(actionId, arg, ctx)` → pomodoro messages / word next / open settings. Increments `uses`.
**Test:** component — typing `g` + Enter calls `openUrl` with google URL; unmatched Enter adds `shake` class.

### Task 9: Pomodoro logic

**Produces (`pomodoro/logic.ts`, all pure, `now` injected):**
- `start(state, settings, now)`, `pause(state, now)`, `resume(state, now)`, `reset(state, now) → { state, session? }`, `skip(state, settings, now) → { state, session? }`, `complete(state, settings, now) → { state, session? }`, `setTag(state, tag)`, `remaining(state, now) → ms`, `phaseMinutes(phase, settings)`.
- `nextPhase`: work → short, or long when `round % roundsUntilLong === 0`; breaks → work (round+1 after long? round increments when a work phase completes).
- Session rules per spec §8.1 (≥1 min partial, breaks never).

**Tests:** full cycle to long break at 4th round, pause/resume preserves remaining, reset at 30s → no session, reset at 5 min → 5 min session, skip break → no session, autoStart false → next phase idle-waiting (`endsAt null`, `pausedRemaining = full`).

### Task 10: Background timer + Pomodoro widget

`pomodoro/messages.ts`: `type TimerMessage = { type: 'start'|'pause'|'resume'|'reset'|'skip' } | { type: 'tag', tag }`.
`background/index.ts`: on message → apply logic, save `timer`, append `sessions`, (re)create alarm `pomodoro` at `endsAt`; on alarm → `complete`, notification, chime (`chime.ts` Web Audio), autoStart handling; `notifications.onClicked` → start next phase.
PomodoroWidget: phase name, big `MM:SS` countdown (ticks every 250 ms from `endsAt`), tag selector (recent tags from sessions + input), Başlat/Duraklat · Atla · Sıfırla.
**Test:** background handler with fake browser: start sets alarm at endsAt; alarm writes session.

### Task 11: Stats logic + widget

**Produces (`stats/logic.ts`):** `dailyTotals(sessions) → Map<dayKey, { minutes, byTag }>`, `level(minutes) → 0..4` (0, <30, <60, <120, ≥120), `heatmap(totals, today, weeks=18) → Cell[][]` (columns of 7, Monday first, future days `null`), `streak(totals, today)`, `tooltip(day, total) → string`.
**Tests:** level boundaries 0/29/30/59/60/119/120; heatmap 18×7 last column contains today; streak counts yesterday-back when today empty; broken by gap.
StatsWidget renders grid + tooltip + `🔥 N gün seri · Bugün X`.

### Task 12: Word data, logic, dictionary, widget

- `public/words.json`: `{ "A1": [["word","anlam"], …], …, "C1": […] }`, ~300 per level.
- `word/logic.ts`: `pool(words, level, custom, known)`, `pickDaily(pool, dayKey) → Word | null` (stable hash of day), `nextWord(pool, current)`, `markKnown(state, word)`.
- `word/dictionary.ts`: `parseDictionary(json) → DictionaryData` (first phonetic text, first audio non-empty, first definition, first example), `lookup(word, fetchFn, cache) → DictionaryData | null` (errors → null, successful results cached).
- WordWidget: word, phonetic, 🔊 (Audio), level badge, TR meaning, definition, example, Biliyorum / Sonraki, empty-pool message.
**Tests:** pool excludes known and other levels, includes custom; pickDaily stable for same day; nextWord wraps; parseDictionary on real sample JSON; lookup network error → null, not cached.
